Conclusion: tool calling works in short requests (clean single- and multi-turn, finish=tool_calls), but is unstable in long agentic sessions. This is not a configuration bug: neither structured-output, nor lenient-assistant-history, nor penalties eliminate marker leakage into the text. It is a behavior of the Inkling 2 Mini model.

Direct API with a defined tool: valid finish=tool_calls, regardless of reasoning_effort, penalties or post_thinking.
