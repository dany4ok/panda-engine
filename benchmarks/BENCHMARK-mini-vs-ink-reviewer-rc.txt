Date: 2026-11-24
Hardware: RTX 5070 Ti 16 GB, both models served sequentially on 127.0.0.1:8080

METHOD
------
Same five prompts were sent through the OpenAI-compatible /v1/chat/completions
endpoint of each model, with temperature=0 and reasoning_effort=low, identical
max_tokens=1024. Criteria were fixed before execution. The only thing changed
between runs was the server loaded on port 8080:

  ink  = inkling-2-mini                    (NInfer, UD-IQ1_M, flags from start.ps1)
  mini = minicpm-v-4.7-35b-a3b-q4_k_m     (Poly-strata strata engine, Q4_K_M)

Engine flags for ink were unchanged: --presence-penalty 0 --frequency-penalty 0
--structured-output --spec none --reasoning-loop conclude --expert-residency device.
The ink server was restored on port 8080 after the test; MiniCPM was stopped.

VERDICT
-------
Inkling 2 Mini is the better choice for reviewer / reality-checker agents:
~2.7x faster decode, ~5-8x faster prompt processing, and the final answer is
always in `content`. MiniCPM matched the code-review quality (3/3 bugs found,
with fewer false positives) but in 2 of 5 probes put the answer in `reasoning`
and returned `content: null`, which an OpenCode agent sees as an empty reply.

RECOMMENDATIONS
---------------
1. Keep reviewer/checker unpinned and choose the model per session; use ink for
   interactive review/check work.
2. Do not set max_tokens below ~256-512. With max_tokens=64 both models spent
   the entire budget in reasoning and emitted no final answer.
3. reasoning_effort=low is enough for this class of task; max added time without
   a measured quality gain in these probes. The published config uses low.
4. If MiniCPM is used, check the `reasoning_content` -> `content` mapping in
   serve/server.py; short answers otherwise appear empty in OpenCode.
5. MiniCPM speculative decoding has uneven acceptance and caused the 18.3 s
   outlier; disable the draft for short prompts.
6. Reserve MiniCPM for batch or vision work, not latency-sensitive agent chains.

LIMITATIONS
-----------
One pass per prompt, five prompts, direct API calls, not the full A-F harness.
Inkling already has 98/98 in the full harness (see logs/tool-fix-evidence.txt);
MiniCPM has 98/98 as well (see README benchmark summary) but at 387.5 s vs 298.6 s.
This report therefore measures short-answer reliability, reasoning-channel
placement and raw speed, not full agentic task completion.
